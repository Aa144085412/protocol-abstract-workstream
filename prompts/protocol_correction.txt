WHAT YOU MAY CHANGE

  swap ATAC FRiP/TSS for CUT&Tag signal-to-noise / fraction-in-peaks-for-the-mark

- You MAY correct materials/kit roles (e.g. note a 10x scATAC v2 kit is used as
  the single-cell barcoding chemistry for a CUT&Tag assay, not as an ATAC assay).

RULES
- Make ONLY the changes the correction implies (plus tightly coupled consequences).
  Preserve every unrelated step, value, and field exactly.
- PRESERVE confirmed uncertainty objects. Do NOT change or overwrite a value that is
  source_confirmed / kit_confirmed / calculated / user_confirmed unless the user's
  correction is explicitly about THAT value. If a correction implies a different
  value for an otherwise-confirmed slot, surface it in "open_questions_for_human"
  as a conflict rather than silently overwriting it.
- Do NOT invent exact volumes/times/temperatures/speeds/catalog numbers. Where a
  new step needs a value the user did not give, write "[confirm with source protocol]".
- Keep step_id stable for steps you keep; assign new step_ids (continuing the
  numbering) for steps you add. Renumber step_number to stay 1..N in order.
- Record what you changed honestly.
